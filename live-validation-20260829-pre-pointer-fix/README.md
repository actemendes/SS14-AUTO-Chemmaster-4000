# ChemMasterAssistant

Локальный помощник для «Химмастера 4000» в клиенте Space Station 14. Программа читает уже открытый интерфейс на стороне клиента и выполняет только обычные пользовательские клики Windows. Она не записывает память процесса, не вызывает административные API и не отправляет собственные сетевые команды серверу.

## Требования

- Windows 10 или 11 x64;
- запущенный в той же пользовательской сессии клиент SS14;
- ровно один подходящий процесс клиента;
- открытый обычным способом интерфейс «Химмастера 4000».

Пакет self-contained: устанавливать .NET, PowerShell, Codex, GPT, Computer Use или браузер не требуется. Интернет для чтения аппарата, планирования и приготовления не используется.

## Первый запуск

1. Распакуйте всю папку в доступное для записи место. Не запускайте EXE прямо из архива.
2. Запустите `ChemMasterAssistant.exe`.
3. Запустите SS14, подойдите к аппарату и откройте его обычный интерфейс.
4. Если программа показывает «Нужна калибровка», выполните мастер калибровки. Поставляемый `chemmaster-calibration.json` намеренно не привязан ни к одному окну.
5. Не меняйте размер клиентской области, DPI или UI scale после калибровки. Координаты профиля хранятся в физических пикселях клиентской области; перемещение окна допустимо только после успешной повторной проверки его положения программой.
6. Загрузите исходные реагенты и убедитесь, что входная мензурка пуста.
7. Выберите лекарства, объёмы и режим `make` или `ensure`, просмотрите план и отсутствующие ингредиенты, затем явно запустите выполнение.

## Безопасная остановка

Глобальная аварийная клавиша — `F12`. Она запрещает новые клики до явного сброса аварийной блокировки и нового запуска. Программа сначала использует Windows `WM_HOTKEY`, а если bare F12 уже занят или зарезервирован — несупрессивный low-level keyboard hook текущего сеанса. Активный backend показан в строке безопасности; если недоступны оба, запуск кликов блокируется.

Во время выполнения:

- не управляйте тем же Химмастером параллельно;
- не закрывайте панель и не меняйте режим, сортировку, размер окна или DPI;
- следите за ожидаемым и фактическим изменением в окне программы;
- при неожиданном изменении буфера продолжайте только после безопасной повторной проверки.

Каждое действие должно подтверждаться новым состоянием аппарата. Истечение timeout не считается подтверждением и не вызывает повторный клик.

## Локальные файлы

- `chemistry-recipes.json` — версионированный каталог рецептов SS220 Wiki;
- `chemistry-game-rules.json` — зафиксированные правила реакций;
- `chemistry-selections.json` — категории и псевдонимы лекарств;
- `chemmaster-calibration.json` — пользовательская привязка координат;
- `settings.json` — безопасные локальные настройки;
- `logs\` — локальные JSONL-журналы действий.

Не заменяйте каталоги и калибровку во время исполнения. Обновление рецептов — отдельная операция, для которой может требоваться Интернет; уже собранный каталог во время игры работает полностью offline.

## Ограничения

- Нагрев, электролиз, центрифугирование и другие внешние операции автоматически не выполняются.
- При нескольких клиентах, закрытой панели, неактивном окне, несовпавшем DPI/размере или неоднозначном изменении состояния клики должны быть заблокированы.
- После обновления SS14 внутренний layout может измениться; в таком случае потребуется новая совместимая версия программы или повторная калибровка.

## Если программа не начинает работу

Проверьте, что запущен один клиент, ChemMaster открыт, окно SS14 активно, мензурка пуста, калибровка завершена, размер окна и DPI совпадают, а аварийная остановка не активна. Точная причина блокировки и журнал находятся в интерфейсе программы и папке `logs`.

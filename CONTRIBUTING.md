# Разработка ChemMasterAssistant

Этот файл предназначен для тех, кто хочет собрать программу из исходников или внести изменения. Обычному пользователю достаточно инструкции в `README.md`.

## Требования

- Windows 10/11 x64;
- PowerShell 7 или Windows PowerShell;
- .NET 10 SDK;
- Интернет для первой загрузки зависимостей.

## Сборка готовой версии

Из корня репозитория выполните:

```powershell
.\publish.ps1
```

Скрипт создаст переносимую папку `ChemMasterAssistant`. Она является результатом сборки и не добавляется в Git.

## Проверка изменений

Полный набор тестов:

```powershell
.\test.ps1
```

Отдельные проверки можно запускать скриптами `test-*.ps1`. Исходники тестов и сценарии из папки `tests` хранятся в репозитории, а созданные ими отчёты и временные сборки — нет.

## Основные папки

- `src/ChemMasterAssistant` — окно приложения;
- `src/ChemMaster` — чтение состояния, каталог рецептов, планирование и выполнение;
- `src/Shared` — общий код;
- `tests` — автоматические проверки и сценарии;
- `package` — файлы, которые добавляются в готовую сборку;
- `docs` — подробные технические заметки.

## Перед коммитом

1. Запустите `git status` и убедитесь, что в изменения не попали сборки, журналы и личная калибровка.
2. Выполните `.\test.ps1`.
3. Если менялось поведение готового приложения, выполните `.\publish.ps1` и проверьте созданный пакет.

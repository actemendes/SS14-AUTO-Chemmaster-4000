# ChemMasterAssistant для Space Station 14

ChemMasterAssistant помогает готовить реагенты через «Химмастер 4000». Вы выбираете нужные вещества и объём, проверяете предложенный план, а программа нажимает обычные кнопки в уже открытом окне игры.

Программа работает локально на компьютере. Она не требует входа в аккаунт, не отправляет команды серверу и не меняет файлы игры.

> Используйте помощник только там, где это разрешено правилами сервера. Ответственность за использование лежит на игроке.

## Что понадобится

- Windows 10 или 11 (64-битная версия);
- один запущенный клиент Space Station 14;
- открытое окно «Химмастера 4000»;
- исходные реагенты в аппарате.

## Установка

1. Откройте раздел [Releases](https://github.com/actemendes/ss14-chemmaster/releases) и скачайте архив последней версии.
2. Распакуйте архив в обычную папку. Не запускайте программу прямо из архива.
3. Запустите `ChemMasterAssistant.exe`.

Устанавливать .NET, PowerShell или другие программы для готовой версии не нужно.

## Первый запуск

1. Запустите SS14 и откройте «Химмастер 4000».
2. В помощнике нажмите кнопку подключения.
3. Если программа попросит калибровку, пройдите её по подсказкам на экране.
4. Убедитесь, что входная мензурка пуста.
5. Выберите нужные вещества и укажите объём.
6. Проверьте план и список недостающих компонентов.
7. Запустите приготовление.

Пока идёт приготовление, не закрывайте панель аппарата, не меняйте размер окна игры и не управляйте тем же аппаратом вручную.

## Как остановить программу

Нажмите `F12`, чтобы немедленно запретить новые клики. После аварийной остановки потребуется явный сброс в приложении и новый запуск приготовления.

Если переключиться на другое окно, помощник автоматически поставит работу на паузу. Продолжение возможно только после возврата к проверенному окну SS14.

## Что программа пока не делает

- не выполняет нагрев, электролиз, центрифугирование и другие действия вне «Химмастера»;
- не работает одновременно с несколькими клиентами игры;
- может потребовать новую калибровку после обновления интерфейса SS14;
- останавливается, если состояние аппарата изменилось неожиданно.

## Если что-то не работает

Проверьте следующее:

- запущен только один клиент SS14;
- панель «Химмастера 4000» открыта;
- окно игры активно;
- входная мензурка пуста;
- размер окна не менялся после калибровки;
- аварийная остановка `F12` не включена.

Причина остановки также показывается в окне помощника.

## Для разработчиков

Для сборки нужен .NET 10 SDK. Готовая переносимая папка создаётся командой:

```powershell
.\publish.ps1
```

Все проверки запускаются командой:

```powershell
.\test.ps1
```
